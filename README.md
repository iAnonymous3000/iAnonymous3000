# Sooraj Sathyanarayanan

I am a **Program Manager at Brave** and a cybersecurity and privacy researcher. I build open-source security tools and write practical guides for understanding how software handles data. I hold an **MS in Cybersecurity from Northeastern University**.

[Website](https://profincognito.me/) · [Research](https://profincognito.me/research/) · [Google Scholar](https://scholar.google.com/citations?user=NwIwfYkAAAAJ) · [LinkedIn](https://www.linkedin.com/in/soorajsathyanarayanan/)

## Selected projects

| Project | What it does |
| --- | --- |
| [Site Behavior Lab](https://github.com/iAnonymous3000/site-behavior-lab) | Records requests, cookies, storage, browser signals, and consent behavior during automated website visits. Reports connect findings to recorded evidence and explain scan conditions and coverage limits. |
| [Brave Nightly Change Tracker](https://brave-experiments.github.io/nightly-tracker/) | A public review interface for merged `brave/brave-core` pull requests and changes relevant to Brave Nightly. |
| [Trace](https://github.com/iAnonymous3000/tracescan) | Uses Rust and WebAssembly to check iPhone sysdiagnose archives for known spyware indicators locally in the browser. Reports distinguish findings from incomplete coverage; a scan cannot establish that a device is free of compromise. |
| [Metadata Remover](https://github.com/iAnonymous3000/metadata-remover) | Inspects and removes structural metadata from supported images, documents, audio, and video locally in the browser, then checks cleaned files again. It does not remove sensitive information visible in the content itself. |
| [QRWarden](https://github.com/iAnonymous3000/qrwarden) | A pre-release QR inspector that displays decoded content and URL properties without visiting the destination during inspection. It does not certify that a link is safe. |
